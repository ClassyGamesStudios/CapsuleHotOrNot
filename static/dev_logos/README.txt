Developer wall logos (landing page, "N developers on the platform").

Drop image files in this folder and they appear on the wall automatically —
no DB row, no code change. Delete a file and it disappears. Files are shown in
filename order, which is why the placeholders are numbered (01_, 02_, ...).

Accepted: .png .jpg .jpeg .gif .webp .svg
Best results: wide logo, roughly 260x120, transparent or dark background.

The .svg files currently here are PLACEHOLDERS — replace them with real
partner logos.
